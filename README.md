# GogoLoot

Vacuum up gear with Automated Master Looting, Automated Rolls, and transparent Distribution Announcements. Quest items, recipes, mounts, pets, and legendaries stay safe. Don't let loot slow down your zug!

## Features

💰 **Master Looter** // Auto-distributes loot to designated players by quality tier while you're Master Looter — destinations update live as group members join and leave.

💬 **Loot & Trade Announcements** // Posts who got what — master loot hand-outs to your party or raid, plus a tidy summary of every completed trade, items, enchants, and gold included.

🎲 **Automated Rolls** // Rolls for you on non-BoP items at or below the quality you choose, with separate settings for parties and raids — pick Pass, Greed, or Need in each. Add BoP items like Scourgestones and Demonic Runes to a Custom Roll List for per-item overrides.

⚡ **Speedy Loot** // Instantly picks up loot without showing the loot window, saving time between every kill.

🦺 **Safety First** // Quest items, books, recipes, mounts, pets, and legendaries are always skipped, and BoP items are never auto-rolled by the threshold.

## Setup

1. Install the add-on, ideally using [CurseForge](https://www.curseforge.com/wow/addons/gogoloot) or [Wago](https://addons.wago.io/addons/gogoloot).
2. Log in.
3. Type `/gl` or `/gogoloot` to open the options panel.
4. Configure your Automated Roll thresholds, Master Loot destinations, and Trade Announcement preferences.
5. Zug zug your way to record Naxx clears. (=

## How It Works

### Minimap Button

Hover for a tooltip showing the current state of Automated Rolls and Speedy Loot. The icon swaps to reflect whether Automated Rolls are on.

| Action | Effect |
| --- | --- |
| Left-click | Toggle Automated Rolls |
| Right-click | Toggle Speedy Loot |
| Shift + Middle-click | Open the options panel |

### Master Looter Pop-up

Become Master Looter and a Quick Settings window opens with the loot method, the loot threshold, and a "Send All Loot To" picker, so a run gets set up without a trip through the options panel. Auto-distribution runs in instances by default, and can be switched on outside of them too. Don't want the pop-up? Turn it off on the Master Looter tab.

### Item Lists

Two lists override the defaults. The **Ignore List** holds items that skip auto-distribution and wait for you to hand them out yourself. The **Custom Roll List** gives specific items their own Need, Greed, or Pass, and it's the only way to automate a roll on a BoP item. Both ship seeded for your expansion, and both restore to those defaults in one click. Drag an item onto a list or paste its Item ID to add it.

### Speedy Loot and Auto Loot

Speedy Loot needs the game's own Auto Loot setting, so GogoLoot turns that on for you while Speedy Loot is enabled and says so in chat when it does. Turn Speedy Loot off and GogoLoot leaves the setting alone. It also stands down completely while you're the Master Looter, so it never hoovers up loot you're about to hand out.

### Profiles

Loot rules live in profiles, so a guild raid setup and a PUG setup can sit side by side and swap in a click.

### Slash Commands

Type `/gl` or `/gogoloot` to open the options panel.
